識別子（列名・テーブル名・別名）のエスケープを厳格にした。

- 識別子に含まれるクォート文字を二重化する（mysql / sqlite では `` ` `` → ` `` `、postgresql では `"` → `""`）。外部入力由来の識別子でクォートを閉じて SQL を差し込めなくなる
- そのまま出力する「クォート済みの断片」を、`.` で区切った断片全体が `` `x` `` / `"x"` / `'x'` で囲まれ、中に同じクォート文字とバックスラッシュを含まないものに限った。`` `t`x `` のような部分的なクォートは、断片全体をクォートし直す
- case_when の when() に渡すフィールドを、column() / where() と同じ規則でエスケープする。`` `users`.id `` や `"users"."id"` のようなクォート済みの断片が二重にクォートされていた不具合を直した
- `quote: null` を指定した場合は、従来どおり識別子をそのまま出力する（エスケープしない）
